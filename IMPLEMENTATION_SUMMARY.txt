💡 HOW IT WORKS (Without API)
═══════════════════════════════════════════════════════════════════════════════

Recipe: "Sauce Tomate Bio" with ingredients [Tomate, Ail, Oignon]

1. User clicks "✨ IA" button
2. Frontend sends: {recipe_name: "Sauce Tomate Bio", ingredients: [...]}
3. Controller validates request
4. Service receives data
5. Checks for AI_API_KEY in .env
   - If exists → Calls configured AI (Groq/OpenAI/etc.)
   - If not → Uses smart fallback generator (THIS IS RUNNING NOW)
6. Fallback detects "sauce" in name → Uses sauce template
7. Generates:
   Description:
   "Notre Sauce Tomate Bio est une sauce artisanale préparée à partir de
    Tomate, Ail, Oignon. Riche en saveurs naturelles, elle offre une 
    texture onctueuse et homogène..."
   
   Instructions:
   "1. Préparer et nettoyer les ingrédients (Tomate, Ail, Oignon)
    2. Chauffer à feu moyen jusqu'à 85-90°C
    3. Maintenir la température 45-60 min selon la texture désirée
    4. Vérifier la consistance et rectifier l'assaisonnement
    5. Verser dans les récipients de stockage à chaud
    6. Refroidir lentement pour éviter les chocs thermiques
    7. Stocker au frais (4-8°C) pendant 3-4 semaines ou congeler"
   
   Eco-Score: B

8. Frontend populates form and shows success
